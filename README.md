# Land Hurl (Forge 1.20.1)

Craft the **Earth Gauntlet** (iron ingots, leather, diamonds - see recipe in game / JEI) or find it in the Tools creative tab.

1. **Empty gauntlet:** aim at the ground or a wall, hold right-click to charge, release. The longer you charge, the bigger the
   cube of land you rip out: 2x2x2 up to 9x9x9 (a new size every half second). Chests, bedrock and fluids are left alone.
2. **Loaded gauntlet (glows):** hold right-click to charge, release to throw. A longer charge throws it faster and harder.
3. When the chunk hits something it hurts it and explodes. Bigger chunk + longer charge = bigger damage and explosion.
   Half of the blocks drop as items where it lands.

Settings (config/landhurl-common.toml): maxSize, ticksPerSize, explosionScale, breakBlocks, dropBlocks.
